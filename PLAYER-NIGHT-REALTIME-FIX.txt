إصلاح مزامنة شاشة اللاعب أثناء الأدوار الليلية

- لم يتم تعديل نظام الغرف أو الانضمام أو إضافة اللاعبين.
- لم يتم تعديل Redis أو Supabase أو Socket.IO server.
- لم يتم تعديل قوانين اللعبة أو gameEngine.
- تم توسيع بصمة حالة شاشة اللاعب لتشمل بيانات الأدوار الليلية الخاصة به.
- تمت إضافة طبقة إصلاح احتياطية تعيد رسم شاشة اللاعب فقط عند وجود اختلاف فعلي بين مرحلة الخادم وما يظهر على الشاشة.
- صفحة البث المباشر تظل تستخدم التحديث المستقر بدون إعادة رسم كامل.
