المرحلة الخامسة

1. استبدال قسم القوانين القديم بالتصميم المعتمد نفسه داخل إطار نيون في أسفل الصفحة الرئيسية.
2. إضافة صورة التصميم إلى public/rules-poster.png مع عرض متجاوب للجوال والكمبيوتر.
3. إصلاح زر نسخ رابط الدعوة باستخدام Clipboard API مع طريقة احتياطية للمتصفحات والتطبيقات.
4. تحسين زر المشاركة، مع نسخ الرابط تلقائيًا عند عدم دعم نافذة المشاركة.
5. تحسين قراءة رمز الغرفة من الرمز المباشر أو رابط الدعوة أو مسار room.
6. توحيد رمز الغرفة وإزالة المسافات والشرطات والرموز غير المطلوبة قبل البحث.
7. إضافة إعداد Capacitor لتجهيز Android وiOS.
8. إضافة أوامر npm لإنشاء ومزامنة وفتح مشاريع Android وiOS.
9. إضافة ملف MOBILE-APP-SETUP.md لشرح خطوات التحويل.

تنبيه: نظام الغرف الحالي محلي ويعمل بين التبويبات على نفس النطاق والجهاز. اللعب بين أجهزة مختلفة يحتاج قاعدة بيانات فورية مثل Firebase أو Supabase.
