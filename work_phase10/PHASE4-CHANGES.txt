المرحلة الرابعة

1. نظام موحد لجميع مهام الليل عبر الشبكة:
- اختيار لاعب واحد.
- زر تأكيد مستقل.
- قفل المهمة بعد التأكيد.
- منع تغيير الاختيار في الجولة نفسها.
- المحقق لا يرى النتيجة إلا بعد اعتماد التحقيق.
- الملك يختار العفو أو الاحتفاظ بالوسام ثم يعتمد القرار.
- خصم وسام الملك عند التأكيد فقط.

2. صفحة قوانين كاملة أسفل الصفحة الرئيسية:
- عدد اللاعبين من 4 إلى 22.
- توزيع اللصوص حسب العدد.
- شرح اللصوص والممرض والمحقق والملك والمواطن.
- شرح مراحل المباراة ونظام التأكيد الموحد.

ملاحظة الاختبار:
تم اجتياز فحص صياغة JavaScript عبر node --check.
تعذر npm install داخل بيئة الإنشاء بسبب عدم توفر حزمة yallist في مستودع npm الداخلي.
